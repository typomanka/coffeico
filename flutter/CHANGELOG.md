## 1.0.0

- First independent release prepared under the `coffeico_plus` package name.
- Preserve the original `Coffeico` class, constant names, and icon codepoints;
  migration requires changing only the dependency and import path.
- Include 34 coffee-related icons through `cupping_bowl`.
- Add reproducible font generation, API regression tests, a runnable example,
  package documentation, provenance records, and CI release checks.

The entries below describe repository history before the independent
`coffeico_plus` package and do not represent releases under this pub.dev name.
